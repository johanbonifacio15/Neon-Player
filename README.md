# Neon Player

Neon Player es un reproductor de música MP3 con una interfaz inspirada en la estética cyberpunk y los colores neón. Su objetivo es ofrecer una forma sencilla y agradable de escuchar música, organizar canciones y crear listas de reproducción personalizadas.

## Características

- **Biblioteca musical:** importa archivos MP3 y organiza tus canciones en un mismo lugar.
- **Reproductor de audio:** reproduce, pausa, cambia de canción y controla el volumen.
- **Listas de reproducción:** crea playlists, agrega canciones y organiza tu música.
- **Modo aleatorio:** reproduce las canciones en un orden diferente.
- **Repetición:** permite repetir una canción o toda la reproducción.
- **Visualizador de audio:** animación que responde al sonido de la música.
- **Gestión de canciones:** renombra y elimina canciones de tu biblioteca.
- **Preferencias:** conserva tus ajustes de reproducción y volumen.

## Interfaz

La aplicación presenta un diseño oscuro con colores neón, animaciones y elementos visuales inspirados en la estética cyberpunk.

## Uso

Puedes acceder directamente a la aplicación desde GitHub Pages:

**[Abrir Neon Player](https://johanbonifacio15.github.io/Neon-Player2/)**

Para comenzar, importa tus archivos MP3 desde la biblioteca y selecciona una canción para reproducirla. También puedes crear listas de reproducción y utilizar los diferentes controles para personalizar tu experiencia.
